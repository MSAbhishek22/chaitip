## Implications for this build (decisions driven by the verified rules)

1. **Fresh build, Mainnet track, solo.** No reuse: none of the user's existing projects (CageCheck, NoteVault, ClinicLink, ChatBoss) send BCH or fit the track without a forced re-plumb, and the rules demand a real mainnet-transaction feature. A fresh, simple, working product also satisfies "original" cleanly.
2. **Every tip IS a mainnet BCH transaction** — the core feature and the eligibility requirement are the same thing.
3. **WizardConnect** (via `@wizardconnect/core`, the Riften Labs SDK) is the wallet integration, with Paytaca/Selene as the wallets that support it (verified via Riften Labs docs + CashScript docs). XO Template is the alternative; not pursued in this build.
4. **Banner, repo link, CashTokens address, Widget Factory presentation** are checklist items for the live site + submission (see `submission/SUBMISSION_DRAFT.md`).
5. **Stream attendance + Telegram confirmation are user taps** — cannot be done by an agent; flagged as the critical path.
6. **Judge-timeout rule drives scope**: one screen, one action (tip), one receipt. No multi-tab maze.
