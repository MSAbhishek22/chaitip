# PROJECT DESIGN REGISTRY — comparison for ChaiTip

Rulebook §1.3: compare the new design against at least the three most recent projects. The new project must be recognisably different in more than accent colour.

## The three most recent projects (as built, from their design constitutions)

| Project | Metaphor | Palette | Layout | Typography | Signature interaction |
|---|---|---|---|---|---|
| **CageCheck** (3 Nov 2026) | Border inspector's stamp desk: cage + stamp + receipt | Paper `#F7F4ED`, ink `#1A1A18`, stamp red/green/amber; light page | Single-column procedural form: paste → check → stamp → receipt | Serif display (Fraunces/Source Serif), monospace receipts | Circular rotated PASSED/HELD/BLOCKED stamp |
| **NoteVault** (3 Nov 2026) | Routing ledger: source → question → audit | Warm off-white `#fafaf7`, ink `#1a1a1a`, amber mock badge; light page | Three-column ledger (notes / ask / audit) | Plain system, monospace audit | Routing + budget audit trail beside every answer |
| **ClinicLink** (3 Nov 2026) | Paper register split in two (phone field page / clinic page) | Calm paper register, red escalation banner; light page | Two-tab register (Phone / Clinic), visit cards | Plain, factual, observational | Danger-sign tick → red escalation banner |

(All three are **light, paper-based, calm, procedural** identities.)

## ChaiTip — how it differs (deliberate, on every axis)

| Axis | ChaiTip | Difference vs the three |
|---|---|---|
| Metaphor | Night street stall: signboard + ticket stub + chai glass | A place and a moment, not a document or a desk |
| Palette | **Dark** — stall green `#0C211A`, marigold `#FFB000`, saffron, cream | Inverts all three: dark background, warm neon accents; no paper |
| Layout | One phone-shaped column (max 560px) at every width; no dashboard grid | No three-column ledger, no two-tab register, no procedural form |
| Typography | Heavy 800–900 uppercase signboard display, tabular numerals for amounts | Loud display type vs the calm/plain type of all three |
| Hero | The stall signboard + amount presets + ONE button in the first viewport | No hero section, no dashboard, no form-first layout |
| Signature interaction | 3D chai glass that fills with a gold coin per confirmed tip; ticket-stub receipt | 3D is the feed itself; none of the three has a 3D scene or a receipt-as-ticket |
| Motion | Steam drift, coin drop with bounce | None of the three uses ambient motion |
| 3D technique | Three.js lathe-geometry glass + instanced coins, drag orbit, CSS fallback | First 3D scene in the user's project set |

**Verdict:** distinct on metaphor, palette (dark vs light), layout, typography, hero, signature interaction, motion and 3D. Passes §1.3.
